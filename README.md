# Helionix AI Systems - marketing website

Static site for helionixai.com (plain HTML/CSS/JS, no build step), hosted on Netlify.

- Pages: `index.html`, services, `about.html`, `contact.html`, `insights.html` + articles, `privacy.html`, `terms.html`
- Styles/scripts: `assets/styles.css`, `assets/main.js`
- Contact form: set `WEB3FORMS_ACCESS_KEY` in `assets/main.js` (get a free key at web3forms.com)
- Deploy: Netlify publishes the repo root (see `netlify.toml`); pushing to `main` redeploys.
